# Cultural Rosetta Stone

Paste in a news event, pick a cultural lens, and get back a short analogy that mirrors the emotional stakes of the story in terms that audience already knows, for example a political shake-up retold as a rugby transfer saga. Output is a single paragraph of 100 words or fewer, generated by Google Gemini.

**Stack:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS · Google Gemini API (`gemini-1.5-flash`)

## How it works

1. The form posts the event text and a culture key to `POST /api/translate`.
2. The route validates the input, finds the culture in `lib/cultures.ts`, and builds a system prompt from that culture's label and description.
3. Gemini returns the analogy, which the UI renders as a card.

The available lenses (pop culture, NRL / rugby, and others) are defined in `lib/cultures.ts`. Add an entry there to add a new one.

## Getting started

Requires Node 20.9+ and a Gemini API key from Google AI Studio.

```bash
npm install
cp .env.example .env.local     # add GEMINI_API_KEY
npm run dev
```
